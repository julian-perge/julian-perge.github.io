# Julian Perge Personal Site

Julian's public personal website, which introduces him and offers his current resume.

## Language

**Site**:
The personal website published at julian-perge.github.io.
_Avoid_: Profile page, portfolio, github.io page

**Profile README**:
The Markdown panel shown at the top of Julian's github.com profile, separate from the Site.
_Avoid_: Profile page

**Home page**:
The Site's main page, authored in Markdown.
_Avoid_: Landing page, index

**Resume page**:
The Site page that shows the Public resume and offers it as a PDF download.
_Avoid_: CV page

**Resume source**:
The one place Julian edits his resume. It holds everything except his phone number.
_Avoid_: Master resume, resume.md

**Public resume**:
The Resume source as published on the Resume page and in its PDF.
_Avoid_: Redacted resume, web resume

**Private resume**:
The Resume source plus Julian's phone number, made only for job applications and never published.
_Avoid_: Full resume, application resume

**Featured project**:
A personal project shown on the Site, such as a game mod Julian wrote or contributes to.
_Avoid_: Portfolio item, side project, repo

**Inspiration site**:
Another engineer's personal website reviewed for layout and content ideas.
_Avoid_: Example profile, reference page
